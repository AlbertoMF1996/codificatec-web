Avisos legales

Última actualización: agosto de 2026.

1. Objeto del sitio web

Este sitio web tiene como finalidad ofrecer información sobre FacturApp, una aplicación de escritorio desarrollada por Codificatec para la gestión de facturas, clientes, empresas y documentos relacionados.

FacturApp funciona principalmente de forma local en el dispositivo del usuario. La información introducida en la aplicación se almacena en el propio equipo del usuario, salvo cuando este realice voluntariamente una operación que requiera comunicación con un servicio externo.

2. Propiedad intelectual

Todos los derechos sobre FacturApp, Codificatec, su diseño, código, textos, imágenes, logotipos, documentación y demás elementos asociados pertenecen a su titular o a sus respectivos propietarios.

Queda prohibida la reproducción, distribución, comunicación pública, transformación o explotación de dichos elementos sin autorización expresa, salvo en los casos legalmente permitidos.

3. Política de privacidad

FacturApp está diseñada para funcionar principalmente de forma local. Codificatec no recibe automáticamente las facturas, clientes, empresas ni demás información que el usuario almacene en la aplicación.

El sitio web no dispone actualmente de registro de usuarios, cuentas personales, área privada, newsletter, publicidad ni formularios de contacto conectados a una base de datos propia.

En caso de que el usuario contacte voluntariamente con Codificatec por correo electrónico, los datos facilitados serán utilizados para gestionar y responder a la consulta, solicitud de soporte o comunicación recibida.

3.1. Responsable del tratamiento

El responsable del tratamiento de los datos personales facilitados voluntariamente a través de los canales de contacto de este sitio web es el titular de Codificatec.

Antes de la publicación comercial definitiva de FacturApp, esta sección deberá incluir los datos identificativos y de contacto exigidos por la normativa aplicable.

3.2. Datos tratados

Se tratarán únicamente los datos que el usuario facilite voluntariamente al contactar con Codificatec, como su nombre, dirección de correo electrónico y el contenido de la comunicación.

3.3. Finalidad

Los datos serán utilizados para atender consultas, responder solicitudes, prestar soporte y mantener las comunicaciones necesarias relacionadas con FacturApp o Codificatec.

3.4. Conservación

Los datos se conservarán durante el tiempo necesario para gestionar la comunicación y, posteriormente, durante los plazos que puedan resultar legalmente exigibles.

3.5. Comunicación de datos

Codificatec no vende datos personales. Los datos no serán comunicados a terceros salvo cuando sea necesario para prestar un servicio solicitado, exista una obligación legal o concurra otra base jurídica que legitime dicha comunicación.

3.6. Derechos del usuario

El usuario podrá ejercer, cuando resulten aplicables, sus derechos de acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad dirigiéndose al responsable mediante el canal de contacto indicado en este sitio web.

4. Cookies

Este sitio web no utiliza actualmente cookies analíticas, publicitarias, de seguimiento ni de personalización propias.

Si en el futuro se incorporasen servicios que utilicen cookies o tecnologías similares que requieran información o consentimiento del usuario, la política correspondiente será actualizada antes de su utilización.

5. Enlaces externos

Este sitio web puede contener enlaces a páginas o servicios de terceros. Codificatec no controla dichos sitios y no se hace responsable de su contenido, disponibilidad, funcionamiento o políticas de privacidad.

6. Legislación aplicable

Estas condiciones se rigen por la legislación española. Para cualquier controversia relacionada con este sitio web se aplicarán las normas sobre competencia judicial que resulten legalmente aplicables.
